# WanderMate Website

A responsive, static product website for **WanderMate**, built for the custom domain `wandermate.taoherba.com`.

## Hosting

The site is published through GitHub Pages. The repository's `CNAME` file binds the GitHub Pages deployment to `wandermate.taoherba.com`; the domain is managed in Manus under **Settings → Deployments → Purchased domains → taoherba.com**.

## Local preview

Open `index.html` in a browser. The site is dependency-free and uses remote editorial travel photography from Unsplash.

## Design

The site uses a cinematic black-and-gold palette and Chinese-language product narrative to introduce WanderMate’s three core experiences: travel-companion matching, shared itinerary planning, and lightweight group collaboration.
